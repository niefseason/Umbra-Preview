# Legal content guidelines

Use games, homebrew, public-domain software and backups you have the legal right to use. Ownership alone may not resolve every jurisdiction's copying or circumvention rules.

UMBRA does not search for, acquire or distribute commercial ROMs, proprietary BIOS, firmware, keys or DRM bypass tools. It imports files explicitly selected by the user and does not execute scripts beside games. The PS2 BIOS guide points to official documentation for dumping a user's own console.

Optional metadata is imported from user-selected JSON. Cover art is imported locally; use artwork you have permission to use. There is no remote metadata or cover service in this build.

Test fixtures in source are synthetic file headers and a mock process, not functional proprietary content. Actual N64 testing used the GPL demo provided by Mupen64Plus; that ROM stays outside deliverables and is excluded by the engine installer.

Console names identify compatibility targets. UMBRA is not affiliated with Sony, Nintendo, PCSX2, Dolphin or Mupen64Plus. No official console logos or commercial game art are bundled.
