# Source review and preview fixes — 2026-09-26

Scope: reviewed controller translation, emulator adapters, launch/session handling, settings recovery, save backup/restore, the Controllers and game-detail UI, status reporting, tests, and release checklist. No applicable AGENTS.md was found in the project or its parent directories. This is a targeted review, not an independent security audit or a completed release certification.

## Fixed

- **Dolphin duplicate trigger input:** action mode set analog L/R to shoulders, then unconditional code replaced them with LT/RT. The same trigger was therefore assigned to native B/Z and analog L/R. Analog shoulder assignments now remain mode-specific. Regression tests cover action mode and switching classic → action to catch stale bindings.
- **Malformed saved device profiles:** null SDL entries and null input maps now recover in memory without discarding valid adjacent profiles or rewriting the original settings file.
- **Custom deadzone retention:** Controllers includes the current saved value among its choices. A value such as 6,000 no longer silently becomes 4,096 when saving unrelated controls.
- **Honest device status:** a connected XInput controller reports DETECTED, with gameplay verification still required.
- **Accurate control descriptions:** the action preset affects N64/GameCube, not PCSX2. The UI describes native inputs rather than promising game actions. N64 X/Y are unassigned in action mode; the manual summary is labeled as applying when action mode is off.

## Next upgrades identified

1. Device-aware SDL enumeration/calibration: action mode currently assumes a raw Xbox layout and overrides custom device expressions. Controller model/driver layouts need measured verification.
2. Title-specific shooter profiles: the generic N64 preset is a button remap, not a verified modern movement/camera implementation. Previous GoldenEye/Perfect Dark suggestions were not established by runtime evidence and must not be treated as compatibility entries.
3. A live input monitor: current values are snapshots refreshed with the Refresh button, not a continuous calibration trace.
4. Capability-specific PS2/GameCube save and state round trips, input/accessibility checks, and clean-machine release gates remain open.
5. Backup/restore deserves a dedicated adversarial review, including redirected paths, Windows path aliases, interrupted writes and partial restore recovery. Existing fixture coverage does not close the independent security-review gate.
