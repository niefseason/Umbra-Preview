## User validation when a game is available

1. Obtain your own lawful Xbox 360 dump using upstream instructions. Do not use a BIOS BIN as a game. This integration does not yet import extensionless STFS/GOD packages; extract to a complete game folder with `default.xex` or use a supported Xbox 360 ISO.
2. Open Launch UMBRA, Add game, select `default.xex` (auto-detected) or ISO (choose Xbox 360), then Play. No separate manual Xenia launch needed.
3. Record game/title revision, file format, engine hash, boot/menu/gameplay results, speed, audible sound, each Xbox button/stick/trigger, fullscreen and exit behavior.
4. Save inside the game, quit normally, relaunch and verify progress. Verify automatic backups independently before relying on recovery. Do not treat fixture backup success as a real emulator save round trip.
5. Report unsupported-title errors with the Xenia log; do not enable random hacks or assume all 360 titles work.
